**Poker** — это продвинутый клиент-серверный симулятор Техасского Холдема (на виртуальные фишки). Проект написан полностью на Kotlin и демонстрирует глубокое понимание архитектуры, математики карточных игр, сетевого взаимодействия в реальном времени (WebSockets) и хардкорной оптимизации Jetpack Compose.

Главная особенность проекта — **гибридная архитектура**. Приложение позволяет играть как на удаленном сервере с игроками по всему миру, так и разворачивать **локальный сервер прямо на Android-устройстве** для игры по локальной сети без интернета.

## 🚀 Ключевые фичи (Killer Features)

  * **Абсолютный Оффлайн (LAN & Hotspot):** Встроенный Ktor-сервер на мобильном устройстве позволяет играть где угодно. Подключитесь к одному Wi-Fi роутеру или **просто раздайте Wi-Fi с одного телефона (Точка доступа / Hotspot)**, чтобы играть в поезде, на природе или в самолете! Поиск комнат происходит автоматически через Network Service Discovery (NSD).
  * **Продвинутая покерная математика:** Подсчет All-in Equity (Монте-Карло, 10 000 итераций) и Live Outs (прямые ауты, runner-runner, drawing dead) в реальном времени.
  * **Run It Multiple Times:** Возможность крутить 2 или 3 борда при All-in (при обоюдном согласии игроков).
  * **Турнирный режим:** Динамический рост блайндов и анте, блокировка новых подключений и запрет ребаев.
  * **Глубокая кастомизация и Performance Mode:** Умная деградация тяжелых анимаций для сохранения 60 FPS на слабых устройствах. Настройка колоды (2/4 цвета, дизайн карт), отображение стека в BB. **Поддержка кастомного масштабирования интерфейса (UI Scale)** — адаптивная перерисовка 70% игровых элементов (аватарки, фишки, ставки) "на лету" без разрушения верстки благодаря нормализованным координатам.
  * **Robust Reconnect & Lifecycle Handling:** Продуманная система восстановления сессии. При потере сети или сворачивании приложения игрок получает 45-секундный grace period. При возвращении клиент бесшовно восстанавливает соединение по WebSocket и синхронизирует актуальный стейт стола без перезагрузки UI. Корректная обработка поворотов экрана и смены конфигурации без потери анимаций.
  * **Идеальная синхронизация:** Самописный алгоритм NTP (Ping-Pong) через сокеты для нивелирования сетевого пинга и идеальной синхронизации таймеров хода между клиентами.

## 🏗 Архитектура проекта

Проект разделен на 3 основных модуля: `shared`, `server` и `app`. Это позволило переиспользовать 100% бизнес-логики и DTO как для боевого бэкенда, так и для оффлайн-сервера внутри Android-клиента.

### 📦 1. Модуль `shared` (Ядро и Математика)

Содержит всю независимую логику игры, модели данных и классы для сетевого общения.

  * **GameEngine:** "Мозг" игры. Изолированный класс, управляющий стейт-машиной раздачи. Автоматически переводит стадии (Preflop -\> Showdown), управляет таймерами (15 секунд на ход с авто-фолдом), обрабатывает дисконнекты (45 секунд grace period на переподключение).
  * **GameRoomService:** Менеджер игровых сессий. Управляет подключением/отключением игроков (включая зрителей - до 9 активных игроков за столом) и хранит инстансы `GameEngine`.
  * **Быстрый Evaluator ("mykey"):** Интегрирован один из самых быстрых open-source алгоритмов оценки силы руки. Используется для мгновенного поиска аутов и симуляции раздач (10k итераций) для подсчета эквити.
  * **DTO:** Единые классы для REST и WebSockets, сериализуемые через `kotlinx.serialization`.

### 🖥 2. Модуль `server` (Backend)

Легковесный и производительный бэкенд на **Ktor Server**.

  * **Стек:** Ktor, JetBrains Exposed v1.1.1 (JDBC + PostgreSQL), JWT Auth, Logback.
  * **База данных:** Таблица `Users` с поддержкой баланса виртуальных фишек, хэшированием паролей. Спроектирована с учетом будущего масштабирования (кастомизация, достижения).
  * **WebSockets:** Весь геймплей работает в Real-time по сокетам. Маршрутизация общается напрямую с `GameRoomService` из `shared` модуля.
  * **Лобби:** Открытый поиск комнат. Возврат актуальной информации о столах (название, количество игроков). Деплой на Linux VPS + Nginx.

### 📱 3. Модуль `app` (Android Client)

Современное Android-приложение, построенное на 100% **Jetpack Compose** и **MVI/MVVM** архитектуре.

#### 🌐 Сеть и Оффлайн-хост

  * **Ktor Client:** Единый клиент для общения с API. Написан кастомный Auth Interceptor для автоматического рефреша JWT токенов (через `AuthEventBus` сессия сбрасывается при невалидности).
  * **OfflineHostManager:** Android-девайс запускает `embeddedServer(Netty)` прямо в фоне приложения.
  * **NSD Discovery:** Реализован поиск и регистрация локальных сервисов через `NsdManager` (включая поддержку нового API Android 14 `UpsideDownCake`), что позволяет игрокам в одной Wi-Fi сети мгновенно находить друг друга.

#### 🎨 Оптимизация UI и Jetpack Compose

Была проделана колоссальная работа по минимизации рекомпозиций и сохранению FPS:

  * **Гранулярный стейт-менеджмент:** Огромный `GameState` разбивается во ViewModel на мелкие `StateFlow`, объединенные через `combine`. Экраны подписываются через `collectAsStateWithLifecycle()`, реагируя только на точечные изменения.
  * **Immutable Collections:** Использование `kotlinx-collections-immutable` для стабильности списков (карт, игроков) и предотвращения лишних перерисовок Compose.
  * **GraphicsLayer & Animatable:** Все перемещения фишек, раздача карт и броски предметов (throwables) анимируются исключительно через `Modifier.graphicsLayer` для работы на уровне GPU, минуя фазы layout/draw.
  * **Умное позиционирование:** Аватарки игроков расставляются с помощью кастомной математики нормализованных координат, которая адаптивно удерживает UI в рамках экрана при любом масштабе (`scaleMultiplier`).
  * **Landscape Mode:** Нативная поддержка альбомной ориентации. Элементы не пересоздаются, а плавно меняют свои модификаторы (позиции и размеры) под широкий стол.

#### ⚡ Performance Mode & Анимации

Уникальная фича для бюджетных смартфонов. Пользователь может на лету включить режим производительности.

  * **Обычный режим:** Богатые многоэтапные анимации. 3D-перевороты карт, пружинящие эффекты (`spring`), объемный 3D-текст победителя с градиентами (Volumetric Text), многослойные анимации с тригонометрией на `Canvas` (эффект "искры/фитиля" на кольцах).
  * **Performance Mode:** Умная деградация UI. Тяжелые `rotation` и `spring` заменяются на элегантные каскадные `slide` и `fade` переходы. 3D фишки заменяются на 2D-векторы. Это сохраняет эстетику раздачи (карты плавно выезжают одна из-под другой), снижая нагрузку на процессор до минимума.
  * **Векторная графика:** Почти все элементы (рубашки карт, масти, UI) нарисованы средствами самого Compose (`Path`, `Canvas`) для экономии памяти. Из растра используются только SVG для старших карт (J, Q, K).

| Категория | Технологии |
| :--- | :--- |
| **Язык** | Kotlin 2.3.10 |
